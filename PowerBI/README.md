# 🚕 NYC Yellow Taxi Mobility Intelligence

**File:**  
`NYC Yellow Taxi Dashboard.pbix`

An end-to-end Power BI project analyzing approximately **49 million NYC Yellow Taxi trips from 2025**.

The dashboard examines mobility patterns, geographic flows, congestion, fare economics, passenger behavior, and data quality across New York City.

## Key Work

- Combined 12 monthly Parquet files into a centralized fact table
- Built a dimensional data model with date, pickup zone, and dropoff zone tables
- Created reusable DAX measures and time-intelligence calculations
- Added dynamic metric selectors and narrative insights
- Built a custom NYC Taxi Zone map using TopoJSON
- Developed congestion, fare, passenger, and anomaly analysis
- Created a dedicated data-quality validation layer

## Dashboard Pages

- Executive Overview
- Movement Explorer
- Time & Congestion Intelligence
- Fare & Passenger Economics
- Data Quality & Anomaly Review

## Key Insights

- Manhattan accounts for the majority of pickup activity
- Demand peaks during evening commuting hours
- Travel speeds fall significantly during high-demand periods
- Credit cards dominate payment activity
- Approximately **9.3% of records are flagged for data-quality issues**, with negative financial values and zero-distance trips representing the largest categories

# 📈 Treasury Capital Markets Command Center

**File:**  
`Treasury Capital Markets Command Center.pbix`

An interactive Power BI dashboard analyzing **U.S. Treasury auction activity, issuance, investor demand, bidder participation, and yield trends**.

The project provides an executive view of Treasury market activity while also including a dedicated model-validation layer.

## Key Work

- Modeled historical and upcoming Treasury auction data
- Built measures for issuance, auction counts, demand coverage, bidder participation, and weighted yields
- Analyzed trends by year and security group
- Compared indirect bidders, primary dealers, and direct bidders
- Built interactive filters and reset functionality
- Created a separate validation page to verify core calculations

## Key Metrics

- Total Offering
- Auction Count
- Demand Coverage
- Indirect Bidder Share
- Weighted High Yield
- Upcoming Offering
- Upcoming Auction Count

## Key Analysis

- Treasury issuance trends over time
- Demand coverage by security group
- Investor participation mix
- Weighted high yields across Treasury securities
- Historical versus upcoming auction activity
